# Hardware Inspection Tool

Internal IT tool for Transpro — runs a network speed test and collects hardware info from the machine running it.

## Features

- Network speed test (download, upload, ping)
- Hardware snapshot: CPU, RAM, OS, model, NIC type & speed
- Security risk assessment report
- Mobile-friendly UI
- Step-by-step guided flow

## Files

| File | Description |
|------|-------------|
| `speedtest-webpage.html` | Main speed test page |
| `security-risks.html` | Security risk assessment report |
| `hw-data.js` | Hardware info (auto-generated by the PowerShell script) |
| `run-speedtest.ps1` | PowerShell script — collects hardware data and opens the tool |
| `run-speedtest.bat` | Batch launcher for the PowerShell script |

## Usage

1. Run `run-speedtest.bat` on the target machine
2. The tool will open in your default browser
3. Follow the on-screen steps to complete the speed test
4. Share results with IT
